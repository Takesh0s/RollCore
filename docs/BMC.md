# Business Model Canvas — RollCore

> Rascunho a revisar pelo grupo. Exportar para `BMC.pdf` na entrega.

| Bloco | Conteúdo |
|---|---|
| Segmentos de clientes | Jogadores e mestres de RPG de mesa (foco em D&D 5e); grupos que jogam presencial e online |
| Proposta de valor | Ficha digital, rolagem de dados com histórico, mesas com convites e calendário, tudo em um só lugar, no web e no celular |
| Canais | Web (Vercel), app Android e iOS, futura versão para PC (Steam) |
| Relacionamento | Autoatendimento, comunidade e tutoriais (planejados) |
| Fontes de receita | Plano FREE e plano PREMIUM (limite de mesas por plano); livraria de conteúdo (planejada) |
| Recursos principais | API Spring Boot, banco PostgreSQL, catálogo SRD de magias, equipe de desenvolvimento |
| Atividades principais | Desenvolver e manter web, app e API; curar conteúdo |
| Parcerias principais | Hospedagem (Render, Vercel), SRD 5.1 (conteúdo aberto), Google (login) |
| Estrutura de custos | Hospedagem, banco de dados, contas de loja (Google Play, Apple), horas de desenvolvimento |
